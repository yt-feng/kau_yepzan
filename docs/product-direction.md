# tiktalk academy：从“课程网站”回到“兴趣驱动的轻学习”

## 产品目标

用户通过刷感兴趣、难度合适的视频，认出一些基础词语或表达，并知道自己这次收获了什么。课程帮助想系统学习的人继续深入；翻译等服务解决具体需求。

北极星候选指标：每周再次认出的有用表达数。不能把播放量、刷完数量或积分直接视为学会。当前版本只保存浏览器内进度，尚未接入跨用户分析，也没有虚构留存数据。

## 这一版的实现

1. 首页以“再刷一条，再多懂一句”为主张。首要按钮进入免费练习，兴趣卡片携带选中的主题进入学习页。
2. 首次只选学习起点、兴趣和小目标，可以跳过。界面语言、视频讲解偏好和学习语言分别表达清楚。
3. 视频推荐综合兴趣、编辑标注的难度、最近首次答题情况和手动反馈。不会宣称这是一套认证的水平测试。
4. 每条视频配一个表达、一句例句和一题小测。答错后有解释和重试，不锁住学习路径。
5. 收藏、错题和到期表达可复习。正确认出后的复习间隔为 1/2/4/7 天；同一天重复答对不会抬高唯一表达数。
6. “我的收获”展示今日新认出的表达、累计认出和收藏。移除模拟他人排行榜及编造的点赞、收藏数。
7. 课程位于首页下方和学习页的轻提示。现有课程是创始人讲授的中文课程，不能冒充英语视频的配套课程。后续如提供同语种、同场景课程，可做更精准的补充推荐。
8. 翻译与个人帮助有独立入口。品牌、邮箱、WhatsApp 标签和现有结账地址继续可达。

## 实际内容边界

- 当前只有 28 条英语教学视频；这一版的兴趣分类基于这些真实内容，暂时不是覆盖所有兴趣的开放内容平台。
- 中/英/阿界面和表达解释不等于三套学习语种。视频本身的阿拉伯语字幕或讲解不会被界面切换改变。
- 学习记录在当前浏览器保存。课程上传、账号和跨设备进度、服务端订单与课程权限属于后续建设。

## 下一轮最值得做的事

先补内容再加复杂功能：围绕已上线的场景，收集可使用的日常生活、食物、工作和故事短视频；每条核对权利、表达、难度、例句和答案。扩展到每个兴趣有足够的新内容与难度梯度，再评价推荐效果。

之后将同语种课程拆成对视频练习有帮助的微课：如“点餐三句话”“听清几个常混淆的音”。用用户的错题或主动学习目标触发推荐，避免在首次体验中强推购买。

需要跨设备和付费内容交付时，再接账号、同步、服务端支付确认和课程权限。保留无需注册即可体验的入口。
